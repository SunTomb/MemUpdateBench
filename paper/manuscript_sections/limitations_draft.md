# Limitations Draft

MemUpdateBench is intentionally controlled. Its primary examples use synthetic, explicit slot-structured updates rather than unconstrained real user histories. This makes stale same-slot burden and final-value transitions measurable, but it limits ecological validity: deployed systems also face implicit updates, paraphrases, corrections, partial information, multilingual facts and uncertain entity or attribute boundaries.

The central identity is an exact `(entity, attribute)` slot. This is a diagnostic invariant, not a claim that all external-memory systems expose or internally use the same identity. The benchmark therefore measures a well-defined slice of memory behavior and should be complemented by broader semantic and conversational tasks.

`slot_direct` is oracle-like. It separates state-management reliability from reader behavior and must not be interpreted as end-user answering. The practical answer result is `slot_prompt`, but even this mode depends on the fixed reader prompt, context serialization and answer model. P8 diagnostics show that order and version metadata can change answer behavior, and the qualified Qwen3.5 boundary shows that stale-context sensitivity is model-dependent rather than universal.

The main P6.3 comparison is an internal controlled method panel. Constrained CRUD is an oracle-like diagnostic upper bound, Raw append and Heuristic CRUD are controlled baselines, and Long25 is a learned compact manager checkpoint. These rows do not establish that one deployable memory product dominates another. External-system results must retain their support envelopes and provenance: Letta and the LangGraph Store/custom-adapter pipeline are joint extraction/storage/reader pipelines on supported subsets, while Mem0 is a preliminary off-the-shelf probe rather than a matched main-table baseline.

The native-system Graphiti study is also bounded. Its development screen did not observe the prespecified current-answer degradation signal and was formally `INCONCLUSIVE`; no held-out validation was spent. The subsequent historical-serving protocol completed a full runtime retry, but the frozen evaluator could not attribute native Chinese relation facts under its narrow public-derived assertion grammar and therefore returned `BLOCKED`. This is an evaluator coverage limitation, not a Graphiti failure or an accuracy zero. No broad historical-serving or cross-system mechanism claim follows.

Finally, the current evidence does not cover implicit updates, real user histories, broad multilingual semantic variation, large-scale external-system rankings, or a multi-model answer panel with uniform access. These are priorities for a separately designed external-validity release. They must not be retrofitted into the frozen Core, Pilot or existing mechanism decision roots.
